I started this site as both a way to learn new technologies and to create a space to showcase my projects and skills. 
The site is hosted on GitHub Pages and deployed using Vite.

I built the site with React, TypeScript, and Material UI, focusing on keeping it simple, fast, and easy to navigate. 
For routing, I used React Router to organize the site into different pages that can be easily updated or expanded. 
Material UI handled the styling and icons. To manage forms efficiently, 
I integrated React Hook Form, which keeps the code maintainable.

Along the way, I learned a lot about react routing and had some trouble with hosting on a static site because at first whenever I refreshed the 
page it would give a 404 error. TO fix it I switched from using a browserrouter to a hashrouter which allowed my site to reload to the root site
every refresh and then go to the path after the # to get to the current page versus giving a 404 error.
Building this site gave me a stronger foundation in React and modern frontend tools, and I’m excited to keep improving it.
## Tech Stack

- React
- Vite
- TypeScript
- CSS
- Material UI
- React Router
